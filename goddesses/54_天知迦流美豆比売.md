## 概要

大年神の三番目の妻で、十柱もの神々を生んだ。その中には竈の神（奥津日子神・奥津比売命）、比叡山・松尾の神として知られる大山咋神、屋敷の神（阿須波神・波比岐神）、山の麓の神（羽山戸神）など、人々の住まいや生活に密着した神々が多く含まれる。大年神の系譜の中核をなす母神である。

## 概説

### 名義
- 「アメ」は美称、「チカル」は「近る（ちかる）」＝近づく、または「光る」、「ミヅ」は水、「ヒメ」は女性。
- 「天から近づく水の姫」＝天から降る雨の女神、あるいは「光る水の姫」とする解釈がある（※推定）。
- 稲作の神である大年神の妻に、天の水（雨）の女神がなることは、稲作と水の関係を表すと解される。

### 御子神の一覧
| 神名 | 神格（通説） |
|---|---|
| 奥津日子神 | 竈（かまど）の神（男） |
| 奥津比売命（亦名 大戸比売神） | 竈の神（女）。古事記に「此は諸人の以ち拝く竈神ぞ」と注記 |
| 大山咋神（亦名 山末之大主神） | 山の神。「近淡海国の日枝の山に坐し、亦葛野の松尾に坐して、鳴鏑を用つ神ぞ」と注記（日吉大社・松尾大社の祭神） |
| 庭津日神 | 庭（屋敷の庭）を照らす日の神 |
| 阿須波神 | 屋敷の地の神（足場・基礎）。宮中で座摩神（いかすりのかみ）として祀られる |
| 波比岐神 | 屋敷の境界の神。同じく座摩神の一柱 |
| 香山戸臣神 | 未詳（香具山との関連か） |
| 羽山戸神 | 山の麓（端山）の神。のちに大気都比売神を娶る |
| 庭高津日神 | 庭を高く照らす日の神 |
| 大土神（亦名 土之御祖神） | 土の神 |

古事記は「上の件の大年神の子、大国御魂神より以下、大土神以前、并せて十六神」とまとめる。ただし実際に数えると、伊怒比売の子5神＋香用比売の子2神＋天知迦流美豆比売の子10神＝17神となり、「十六神」と合わない（伝写上の問題とする説など、数え方には諸説あり）。

## エピソード

### 1. 大年神の妻となり十神を生む
「又天知迦流美豆比売を娶りて生める子は、奥津日子神。次に奥津比売命、亦の名は大戸比売神。此は諸人の以ち拝く竈神ぞ。次に大山咋神、亦の名は山末之大主神。此の神は、近淡海国の日枝の山に坐し、亦葛野の松尾に坐して、鳴鏑を用つ神ぞ。次に庭津日神。次に阿須波神。次に波比岐神。次に香山戸臣神。次に羽山戸神。次に庭高津日神。次に大土神、亦の名は土之御祖神」と記される。

## 祭祀
天知迦流美豆比売を主祭神とする古社は確認できない（※未確認）。
