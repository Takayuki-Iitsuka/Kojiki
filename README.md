- `docs/` の本文ページと、神々の3ディレクトリでは、執筆形式が異なります。後者は「基本情報・概要・概説・エピソード・『日本書紀』等との比較・祭祀・参考資料」の7節構成です。

## 記述の約束事

詳細は [CLAUDE.md](CLAUDE.md) を参照してください。要点は次のとおりです。

- **言語**: 全文日本語。歴史用語は漢字表記を優先します。
- **専門用語**: 初出時に「英語(日本語訳)」の形で併記します。例: paired deities(対偶神)。
- **年の表記**: 「西暦年(皇紀N年・和暦)」とします。皇紀 = 西暦 + 660。例: 712年(皇紀1372年・和銅5年)。
- **字体**: 本文は常用漢字(新字体)に統一します。固有名詞の異体表記は武田版に従い、別本の表記は注記します。
- **出典**: 各ページ末尾に「出典」節を置き、一次資料を優先します。二次資料(Wikipedia・辞典)のみで確認した事項は「二次資料」と明記します。
- **諸説**: 諸説あるものは断定せず、説ごとに論者と出典を併記します。

## 確度マークの見方

| 記号 | 意味 | 使う場面 |
|---|---|---|
| ✅ | 出典で確認済み | 本文の該当箇所を grep 等で確認した事項のみ |
| 🔶 | 未検証(既存知識・推定) | 不確かな情報は必ず付ける。同一段落に混在する場合は文中に明記 |
| ※諸説あり / ※推定 / ※要確認 / ※未確認 | 神々の個別ページで使う注記 | 名義(語源)、比定地、現行の祭神構成など確証のない情報 |
| ［要確認］ | 日本書紀ページで使う注記 | 一次資料の原文照合をしていない箇所 |

**確度マークの付いていない記述を、そのまま学術的な事実として引用しないでください。** 一次資料で確認してから使ってください。

## 底本と引用の方針

- 書き下し文・現代語訳の底本は、武田祐吉校註『古事記』(角川文庫、1956年〈皇紀2616年・昭和31年〉初版)の青空文庫版です。武田は1958年(皇紀2618年・昭和33年)没で、パブリックドメインです。
- 白文(原文)は転載せず、国立国会図書館デジタルコレクションの真福寺本影印へのリンクのみ示します。
- 中文 Wikisource は CC BY-SA 4.0 のため転載しません(リンクのみ)。
- 引用は書き下し文であり、**原文(変体漢文)ではありません**。ページには必ず「書き下し」と明記します。
- 武田の校訂・見出し・脚注は一学説であり、他の校訂本と異なる場合があります。

詳細は [docs/14-原文と底本方針.md](docs/14-原文と底本方針.md) を参照してください。

## ページの追加・更新の手順

1. 新規ページは [docs/_template.md](docs/_template.md) を複製して作ります(神々のページは既存ファイルを雛形にします)。
2. 先頭に「確度」と「最終更新」を記し、末尾に「出典」節を置きます。
3. 確認していない事項には 🔶 を付けます。確認できたら ✅ に改め、出典を追記します。
4. 新しいページは、次の目次にリンクを追加します。
   - 本文: [docs/index.md](docs/index.md)(上・中・下巻の下位ページは各巻の README など)
   - 神々: 該当する目次(`goddesses/README.md` など)
5. 未解決事項は [docs/TODO.md](docs/TODO.md) に追記し、解決したらチェックを入れます。
6. リンク切れがないか確認します(ファイル名に日本語を含むため、相対パスの誤りに注意)。
