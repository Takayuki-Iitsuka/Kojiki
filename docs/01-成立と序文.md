# 成立と序文

> 確度: ✅(序文は武田祐吉校註〈青空文庫〉の書き下し文で確認)  |  最終更新: 2026-11-03

## 序文(上表文)の構成
武田祐吉校註本は序を三つに分ける(見出しは同書による)。

| 節 | 内容 |
|---|---|
| 過去の時代 | 天地開闢から推古天皇までの歴代の事績を概観する。 |
| 古事記の企畫 | 天武天皇が、諸家の帝紀と本辞に虚偽が多いとして、撰録・改訂を企図する。 |
| 古事記の成立 | 元明天皇の詔、安万侶の撰録方針、三巻の区分、献上。 |

## 序文が述べる経緯 ✅
1. 天武天皇は「諸家のもたる帝紀と本辞」が事実と違い虚偽が多いと述べ、これを撰録・討覈して偽を削り実を定めようとした。
2. 舎人の稗田阿礼(年二十八)に、帝皇の日継(帝紀)と先代の旧辞を誦み習わせた。しかし時世が移り、事は行われなかった。
3. 元明天皇が、和銅4年(711年・皇紀1371年)9月18日、太安万侶に詔して、阿礼の誦む旧辞を撰録し献上させた。
4. 和銅5年(712年・皇紀1372年)正月28日、正五位上勲五等太朝臣安万侶が献上した。

> 「和銅四年九月十八日を以ちて、臣安萬侶に詔して、稗田の阿禮が誦める勅語の舊辭を撰録して、獻上せよと宣りたまへば」
> (武田祐吉校註『古事記』序より。底本の脚注番号は除去。→ [14-原文と底本方針](14-原文と底本方針.md))

## 表記方針に関する序文の記述 ✅
- 上古は言と意が共に朴で、文章を漢字で書くのは難しい。訓だけで述べると詞が心に及ばず、音だけで連ねると事の趣が長くなる。
- そのため一句の中に音と訓を交え用い、あるいは一事の内に全く訓で記した。
- 解りにくい所は注で明らかにし、解りやすい所は注さない。姓の「日下」を「玖沙訶」、名の「帯」の字を「多羅斯」と読む類は、元の表記に従って改めない。

## 巻の区分(序の記述)✅
| 巻 | 範囲 |
|---|---|
| 上つ巻 | 天之御中主神から日子波限建鵜草葺不合尊の前まで |
| 中つ巻 | 神倭伊波礼毘古天皇から品陀(応神)の御世の前まで |
| 下つ巻 | 大雀(仁徳)から小治田(推古)の大宮の前まで |

記す範囲は「天地の開闢」から「小治田の御世(推古天皇)」まで。

## 留意点
- 武田の脚注では、安万侶(太安麻呂)の没年は養老7年(723年・皇紀1383年)。✅
- 稗田阿礼は、アメノウズメ命の子孫とされ、性別は男女両説あると注される。✅
- 序文の成立過程・朝廷の関与には不明点や矛盾があるとされる(二次資料)。→ [10-論争点](10-論争点.md)
- 序の文面は、『古事記』全体の真偽問題と切り離せない。序文の記述をそのまま史実の証拠として扱わないこと。
