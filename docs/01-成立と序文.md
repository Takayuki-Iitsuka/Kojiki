# 成立と序文

> 確度: ✅(二次資料のみ)  |  最終更新: 2026-11-03

## 序文の記述
- 天武天皇が稗田阿礼(Hieda no Are)に帝紀・旧辞を誦習(memorized recitation)させた。✅
- 元明天皇の命で太安万侶(Ō no Yasumaro)が筆録し、和銅5年(712年・皇紀1372年)正月28日に献上。✅
- 序文は上表文(memorial to the throne)の形をとる。✅

## 留意点
- 序文の成立過程・朝廷の関与には不明点や矛盾があるとされる。✅ → [10-論争点](10-論争点.md)
- 稗田阿礼の性別は諸説(男性説・巫女説)。✅
