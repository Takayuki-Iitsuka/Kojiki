# 中巻: 応神天皇

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

- 品陀和気命。軽島の明宮に坐す。品陀真若王の三柱の女王を娶る。✅
- 大山守命と大雀命に「兄なる子と弟なる子といづれか愛しき」と問う。✅
- 宇遅野から葛野を望む歌、木幡の道衢で孃子に遇う蟹の歌、日向の諸県君の女 髪長比売を召す件。✅
- 吉野の国主歌: 国主たちが大御酒を献る時の歌。✅
- **文化の渡来**: 海部・山部・山守部・伊勢部を定め、剣池を作る。新羅人の渡来。百済の国主 照古王が牡馬・牝馬を阿知吉師に付けて貢り、和邇吉師を通じて和邇吉師に付けて論語十巻・千字文一巻、併せて十一巻が貢られた。和邇吉師は文首らの祖とされる。✅
- **天之日矛**: 新羅の国主の子 天之日矛が渡来する伝承。妻(阿加流比売)が逃れ、追って難波に至るが渡の神に阻まれる。玉津宝(珠二貫、浪振る比礼など)を持ち渡る。✅(妻の名は本文に見える ✅)
- **秋山之下氷壮夫と春山之霞壮夫**: 伊豆志袁登売を巡る兄弟の争い。✅
- 天皇崩後、大雀命は天下を宇遅能和紀郎子に譲る。大山守命は反して殺され、河に沈む。兄弟は譲り合い、海人の大贄をめぐる話が続く。✅
- 御年130歳、甲午年9月9日崩。御陵は川内の恵賀の裳伏の岡。✅
