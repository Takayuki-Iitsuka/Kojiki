# 中巻: 景行天皇と倭建命

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

## 景行天皇 ✅
大帯日子淤斯呂和気天皇。纏向の日代宮に坐す。后妃・皇子女の記事の後、小碓命(後の倭建命)の物語が続く。御年137歳、御陵は山辺道の上。

## 倭建命(Yamato Takeru)✅
1. **西征**: 小碓命は兄が朝夕の大御食に出て来ない件を「ねぎ教え覚せ」と命じられ、その荒い性情を恐れた天皇に、西方の熊曾建二人の討伐を命じられる。熊曾建は討たれる際に御名を献り、「今よ後、倭建御子と称へまをさむ」と述べた(倭建の名の由来)。✅ 兄に対しては、厠に入る所を捕らえて手足をひき折り、薦に包んで投げ棄てた旨を天皇に述べた(「ねぎ教え覚せ」の実行)。✅
2. **出雲建**: 出雲国に入り、出雲建と結交する。赤檮で偽の刀を作って佩き、共に肥河で沐浴した。先に上がって出雲建の刀を取り替え、「いざ刀合はせむ」と誘い、出雲建が偽刀を抜けないうちに討ち殺した(歌謡24)。✅ 熊曾建の討伐は、姨の倭比売命の衣裳を着て童女の姿になり、宴の酣に胸を刺し通した。✅
3. **東征**: 天皇は東方十二道の荒ぶる神・服わぬ人を言向け和すよう命じる。
   - 尾張国で美夜受比売の家に入るが、婚は帰りにと約す。
   - 走水の海で渡の神が波を立てて船を回す。后(弟橘比売。名は本文に見える)の御櫛が七日後に海辺に寄り、御陵を作った。✅
   - 蝦夷らを言向け、酒折宮で歌を詠む。東の国の造を与えた老人の話。✅
   - 科野坂の神を言向け、尾張に還り美夜受比売と御合し、草薙剣を美夜受比売の許に置いて伊服岐山の神を取りに出発する。✅
4. **最期**: 徒手で取れると言って伊服岐山に登り、白猪に遇う(神の化身)。当芸野で「吾が足得歩まず」と詔り、三重村で「吾が足三重の勾なして、いたく疲れたり」と詔る。能煩野で国思歌を詠み、病が急になる。✅
   - 能煩野の国思歌は「倭は国のまほろば たたなづく青垣 山隠れる倭し美し」(歌謡31)。✅ 続く歌には「命の全けむ人は 畳薦平群の山の熊白檮が葉を…」がある。✅
- 白鳥は河内の志幾に留まり、白鳥の御陵と名づけられたが、さらに天翔り飛び去った。✅
5. **白鳥**: 倭の后や御子たちが下って御陵を作ると、八尋白智鳥となって天翔り、浜に向かって飛び去る。后たちと御子たちは小竹の苅杙に足を切りつつ追う。四つの歌は大御葬に歌われる。✅

- 倭建命の系譜も記される(帯中津日子命ほか)。✅

## 成務天皇 ✅
若帯日子天皇。近つ淡海の志賀の高穴穂宮。御年95歳、乙卯年3月15日崩。御陵は沙紀の多他那美。

## 武田注(要点) ✅
### 景行天皇の后妃・皇子女
- 日子淤斯呂和気天皇: 景行天皇。纏向日代宮は奈良県磯城郡。
- 小碓命: ヤマトタケル命。日本書紀に、父の天皇が皇子の誕生に当たって石臼の上で躍って喜んだから大碓命・小碓命というとある、と武田は注する。
- 若帯日子命: 成務天皇。
- 武田注: 皇子の曽孫の子だから、天皇の孫の孫の子に当たり、それを妃としたというのは時間的に不可能である。ある氏の伝えをそのまま取り入れたもの(注の以下は未確認)。🔶
- 「この三王は太子」: 後世のように皇太子を立てることは無かったが、有力な后妃の生んだ皇子が次に帝位に昇るべき方として予想された。
- 大根王: 開化天皇の孫。
- 「長眼を経しめ」: 長く見ていさせる。待ちぼうけさせる。
- 東の淡水門: 神奈川県から千葉県安房郡に渡る水路。倭の屯家は、大和国の租税収納所。

### 倭建命の西征と出雲建
- 「もはら汝ねぎ」: なだめ乞う。「いかにかねぎつる」はどんなふうになだめ乞うたのか。
- 熊曽建: クマソは地名で、クマの地(熊本県)とソの地(鹿児島県)とを合わせ称する。タケルは勇者の義。物語では兄弟二人となっている。
- 「御髪を額に結はせり」: 男子少年の風俗。姨倭比売命は、父の妹に当たる。
- 御室楽: 新築を祝う酒宴。
- 「今よ後」: 今から後。ヨは助詞で、ユ・ヨリに同じ。倭建御子: 日本書紀には日本武尊と書く。
- 神河の神・穴戸の神: 海峡の神。
- 出雲建: この物語は、日本書紀では出雲振根がその弟飯入根を殺した話になっている。詐刀はにせの刀、木刀。
- 歌謡24の「やつめさす」: 枕詞。「八雲立つ」の転訛。日本書紀にはヤクモタツになっている。「黒葛多纏き」は柄や鞘に植物の蔓を沢山巻いてある意。「さ身無しにあはれ」の「アハレ」は感動を表示している。

### 東征
- 東方十二道: 崇神天皇の条の注を参照([03-崇神天皇](03-崇神天皇.md))。
- 比比羅木の八尋矛: ヒイラギの木の柄の長い矛。ヒイラギは葉の縁にトゲがあり、魔物に対して威力があるとされる。
- 相武国: 相模国に同じ。神奈川県の一部。
- 「向火を著けて」: こちらから火をつけて向こうへ焼く。野火に逢った時には手元からも火をつけて先に野を焼いてしまって難を免れる方法である。
- 焼遣: 焼津とする伝えもある。静岡県の焼津町がその伝説地であるが、相武国の事としているので問題が残る。
- 走水海: 浦賀水道から千葉県に渡ろうとした。弟橘比売命: 日本書紀に穂積氏の女とする。
- 「八重を波の上に敷きて」: 波の上に多くの敷物を敷いて。海上で風波の難にあうのは、その海の神が船中の人または物の類を欲するからで、その神の欲するものを海に入れれば風波が静まるとする思想。
- 歌謡「さねさし」: 枕詞。嶺が立っている義だろうとする。嶺は静岡県とすれば富士山、神奈川県とすれば大山である。
- 御陵(櫛の陵): 所在不明。浦賀市走水に走水神社があって、倭建命と弟橘姫とを祭る。
- 蝦夷: アイヌ族をいう(武田注)。酒折宮: 山梨県西山梨郡。筑波: 茨城県の地名。
- 「かがなべて」: 日を並べて。
- 東国の造: 東方の国の長官。実際上はそのような広大な土地の国の造を置かない。
- 科野国: 今の長野県。科野の坂: 長野県の伊那から岐阜県の恵那に通ずる山路。木曽路は奈良時代になって開通された。
- 伊服岐山: 滋賀県と岐阜県との境にある高山。

### 思国歌・白鳥
- 「徒手に直に取りてむ」: 退治しよう。「言挙して」は言い立てをして。
- 玉倉部の清泉: 滋賀県坂田郡の醒が井はその伝説地。
- 当芸野: 岐阜県養老郡。「空中を飛んで行こうと思ったが」「たぎたぎしく」(びっこを引く形容)。
- 杖衝坂: 三重県三重郡。尾津前: 三重県桑名郡。サキは海上陸上に限らず突出した地形をいう。ここは陸上。
- 三重村: 三重県三重郡。「吾が足三重の勾」は、餅米をこねて、ねじ曲げて作った餅のようだ、の意。
- 能煩野: 三重県鈴鹿郡。
- 国思歌(歌謡31): 「国のまほろば」は最もすぐれたところ。マは接頭語、ロバは接尾語。日本書紀にはマホラマ。「青垣」は重なり合っている青い垣、山のこと。「畳薦」は枕詞で、敷物にしたコモ(草の名)。平群の山は奈良県生駒郡。「髻華に挿せ」は、美しい白檮の葉を頭髪にさせ、の意。ウズは髪にさす飾りで、もと魔よけの信仰のためにさすもの。
- 「この歌は思国歌」: 歌曲としての名。「こは片歌」は五七七の三句の歌の称。以上三首、日本書紀に景行天皇の御歌とする。
- 「つるぎの大刀」: 普通ツルギは両刃、タチは片刃の武器をいうが、厳密な区別ではない。
- 白鳥陵: 「八尋白智鳥」は大きな白鳥。倭建命の神霊が化したものとする。「小竹の刈杙」は小竹の刈った跡。「腰なづむ」は腰が難渋する。
- 河内国の志幾: 大阪府南河内郡。
- 倭建命の系譜: 伊玖米天皇は垂仁天皇。陵(山辺の道の上)は奈良県磯城郡。

### 成務天皇
- 近つ淡海の志賀の高穴穂宮: 滋賀県滋賀郡。
- 建内宿禰を大臣とした: 宮廷の臣中の最高の位置。この後、建内宿禰の子孫がこれに任ぜられた。
- 大国小国: 諸国の意。
