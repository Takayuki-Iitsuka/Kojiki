# 中巻: 欠史八代(綏靖〜開化)

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

「欠史八代(ketsushi hachidai)」は、事績の物語がほぼなく系譜・宮・后妃・皇子女のみを記す第2〜9代の天皇を指す通称。✅(二次資料に基づく用法)

| 代 | 天皇(本文の名) | 宮 |
|---|---|---|
| 2 | 神沼河耳命(綏靖) | 葛城の高岡宮 |
| 3 | 師木津日子玉手見命(安寧) | 片塩の浮穴宮 |
| 4 | 大倭日子鉏友命(懿徳) | 軽の境岡宮 |
| 5 | 御真津日子訶恵志泥命(孝昭) | 葛城の掖上宮 |
| 6 | 大倭帯日子国押人命(孝安) | 葛城の室の秋津島宮 |
| 7 | 大倭根子日子賦斗邇命(孝霊) | 黒田の廬戸宮 |
| 8 | 大倭根子日子国玖琉命(孝元) | 軽の堺原宮 |
| 9 | 若倭根子日子大毘毘命(開化) | 春日の伊耶河宮 |

- 漢風諡号(綏靖など)は本文にない(後世の命名)。🔶
- 各天皇の后妃・皇子女・御年・御陵は系譜として記される。ここでは宮名のみ取り込み、詳細は今後。

## 武田注: 宮・陵の所在 ✅
武田は綏靖天皇の条で、以下八代は、多少の挿入はあろうが、大体帝紀の形が残っていると考えられる、と注する。

| 天皇 | 宮の所在(武田注) | 陵・その他(武田注) |
|---|---|---|
| 綏靖 | — | 衝田岡: 奈良県高市郡。神武天皇陵の北にある |
| 安寧 | 片塩浮穴宮: 奈良県北葛城郡 | 淡道御井宮(皇子女の条): 兵庫県三原郡。陵は畝火山の美富登で、畝火山の南のくぼみ。二女王(縄伊呂杼ほか)は孝霊天皇の妃 |
| 懿徳 | 軽境岡宮: 奈良県高市郡 | 畝火山の真名子谷の上: 畝火山の南 |
| 孝昭 | 葛城掖上宮: 奈良県南葛城郡 | — |
| 孝安 | 葛城室秋津島宮: 奈良県南葛城郡 | — |
| 孝霊 | 黒田廬戸宮: 奈良県磯城郡 | 片岡馬坂の上: 奈良県北葛城郡 |
| 孝元 | 軽堺原宮: 奈良県高市郡 | 建内宿禰の事蹟は応神天皇の条以下に見える |
| 開化 | 春日伊耶河宮: 奈良市 | — |

- 孝霊天皇の条: 針間の氷河の前(兵庫県加古郡)に忌瓮を居えて、清らかな酒瓶を置いて神を祭り、行旅の無事を祈った。針間を道の口としたのは、播磨国を道の入口として、の意。吉備国は後の備前・美作・備中・備後の四国の総称。
- 孝元天皇の条: 大毘古命の事蹟は崇神天皇の条にある。建内宿禰の事蹟は応神天皇の条以下にあり、この子孫は勢力を得たので、その子を詳記してあるが、帝紀としては加筆であろう(武田注)。
- 開化天皇の条: 沙本毘売命は垂仁天皇の皇后で、その物語は垂仁天皇の条にある。御上の祝がもちいつく神(天之御影神)は、滋賀県野洲郡の三上の神職が祭る。
- 注: 宮の所在の比定は武田の注による。後の研究による修正は未調査。🔶
