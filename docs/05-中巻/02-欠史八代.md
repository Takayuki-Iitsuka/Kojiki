# 中巻: 欠史八代(綏靖〜開化)

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

「欠史八代(ketsushi hachidai)」は、事績の物語がほぼなく系譜・宮・后妃・皇子女のみを記す第2〜9代の天皇を指す通称。✅(二次資料に基づく用法)

| 代 | 天皇(本文の名) | 宮 |
|---|---|---|
| 2 | 神沼河耳命(綏靖) | 葛城の高岡宮 |
| 3 | 師木津日子玉手見命(安寧) | 片塩の浮穴宮 |
| 4 | 大倭日子鉏友命(懿徳) | 軽の境岡宮 |
| 5 | 御真津日子訶恵志泥命(孝昭) | 葛城の掖上宮 |
| 6 | 大倭帯日子国押人命(孝安) | 葛城の室の秋津島宮 |
| 7 | 大倭根子日子賦斗邇命(孝霊) | 黒田の廬戸宮 |
| 8 | 大倭根子日子国玖琉命(孝元) | 軽の堺原宮 |
| 9 | 若倭根子日子大毘毘命(開化) | 春日の伊耶河宮 |

- 漢風諡号(綏靖など)は本文にない(後世の命名)。🔶
- 各天皇の后妃・皇子女・御年・御陵は系譜として記される。ここでは宮名のみ取り込み、詳細は今後。
