# 中巻: 垂仁天皇

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

- 伊久米伊理毘古伊佐知命。師木の玉垣宮に坐す。✅
- **沙本毘古の叛乱**: 皇后 沙本毘売の兄 沙本毘古が妹に「夫と兄といづれか愛しき」と問い、謀反を迫る。天皇は欺かれたと知り軍を起こして撃つ。后は懐妊し、愛重みもあって三年経っていた。天皇は子の名は母が付けるものと命じる。✅
- **本牟智和気**: 御子を二俣小舟で市師池・軽池に浮かべて遊ぶ。天皇の夢に出雲大神が現れ、「我が宮を天皇の御舎のごとく修理めよ」と告げる。出雲に至り大神を拝み、肥河に黒樔橋を作り仮宮を設ける。御子は肥長比売と一宿婚するが、窃かに覗くと蛇であり、畏れて逃げた。✅
  - 🔶 御子が口をきけなかったことは既存知識。この節の書き出しは未確認。
- 丹波の四女王(美知能宇斯王の女たち)を召す。✅
- 多遅摩毛理を常世国に遣わし、時じくの香の木の実を求めさせる。✅
- 大后比婆須比売命の時に石祝作・土師部を定めた。✅
- 御年153歳、御陵は菅原の御立野の中。✅
