# 中巻: 崇神天皇

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

- 御眞木入日子印恵命。師木の水垣宮に坐す。✅
- 役病(流行病)が多く起こり、人民が尽きようとした。天皇が愁え嘆いて神牀に在した夜、大物主神が夢に現れ、意富多多泥古に祭らせるよう告げた。意富多多泥古が祭ると疫病は止み、国は平らいだ。✅
- 意富多多泥古が神の子である由来: 活玉依毘売の許に夜ごと壮夫が通い、妊った。親の指示で糸を衣に付けると、糸は鉤穴から出て、美和山の神の社に留まった。✅(大物主神と三輪の関係を語る伝承)
- 将軍の派遣: 大毘古命を高志道に、その子 建沼河別命を東方十二道に遣わす。山代の幣羅坂で少女が歌を詠み、大毘古は異変を知る。建波邇安王が和訶羅河で軍を興して対峙する。✅
- 天下が平らぎ、人民が富み栄え、初めて「男の弓端の調」「女の手末の調」を貢がせた(課税の起源譚)。✅
- 御年168歳、戊寅年12月崩。御陵は山辺道の勾岡の上。✅

## 武田注(要点) ✅
- 御真木入日子印恵命: 崇神天皇。師木水垣宮は奈良県磯城郡。
- 「陵に人垣を立てたり」: 人を埋めて垣とするもの(殉死の風習に関する記述)。
- 神牀: 神に祈って寝る床。夢に神意を得ようとする。「神の気起らず」は神のたたり。
- 駅使: 馬に乗って行く使。
- 美努村: 意富多多泥古を見出した所で、大阪府中河内郡。日本書紀には茅渟県の陶邑としている。これは和泉国である。
- 神主: 神のよりつく人。御諸山: 奈良県磯城郡の三輪山。
- 天之八十平瓮: 多くの平たい皿。既出の語。
- 宇陀の墨坂: 奈良県宇陀郡。大和の中央部から見て東方の通路の坂。赤色の楯矛を祭る(奉ることによって祭をする)。神に武器を奉って魔物の入り来るを防ごうとする思想。
- 大坂の神: 奈良県北葛城郡、二上山の北方を越える坂。大和の中央部から西方の坂。墨色の楯矛を祭る。
- 活玉依毘売の話: 人間ならざる者の正体を見現すために行う方法。ヘソヲ(紡麻)は糸巻にまいた麻。ただ遺れる麻は、糸巻に残った麻。

### 将軍の派遣
- 大毘古命: 孝元天皇の御子。
- 東の方十二道(十二国): 伊勢(志摩を含む)、尾張、参河、遠江、駿河、甲斐、伊豆、相模、武蔵、総(上総・下総・安房)、常陸、陸奥の十二国であるという。
- 旦波国: 京都府の北部。
- 腰裳服せる少女: 腰に裳をつけた少女。裳は女子の腰部にまとう衣服。
- 山代の幣羅坂: 大和国から山城国に越えた所の坂。
- 少女の歌: 後方の戸から人目をはずして、窺うことを知らずに(「ニ」は打消の助動詞ヌの連用形)の意の注がある。見えずして忽ちに失せたのは、神が少女に化して教えた意になる。
- 和訶羅河: 木津川の別名。久須婆の渡: 大阪府北河内郡、淀川の渡り場。波布理曾能: 京都府相楽郡。
- 相津: 福島県の会津。
- 弓端の調・手末の調: 男子が弓によって得た物の貢物(獣皮の類)と、女子の手芸によって得た物の貢物(織物・糸の類)。
- 「初国知らしし」: 新しい土地を領有した。
- 依網池: 大阪市東成区。軽の酒折池: 奈良県高市郡。
- 辺の道の勾の岡の上: 奈良県磯城郡(崇神天皇の陵のある所)。
