# 記紀比較

> 確度: ✅(武田解説・二次資料で確認。🔶は未確認)  |  最終更新: 2026-11-03

『古事記』と『日本書紀』を併せて「記紀」(Ki-Ki)と呼ぶ。日本書紀の詳細は [日本書紀](nihon-shoki.md) を参照。

## 基本の対比
| 項目 | 古事記 | 日本書紀 | 確度 |
|---|---|---|---|
| 成立 | 和銅5年(712年・皇紀1372年) | 養老4年(720年・皇紀1380年) | 古事記✅、書紀🔶(一次確認は未了) |
| 巻数 | 3巻(上・中・下) | 30巻 | ✅(武田解説) |
| 文体 | 変体漢文+音仮名 | 漢文(正格の漢文) | ✅(武田解説) |
| 範囲 | 天地初発〜推古天皇 | 神代〜持統天皇(🔶) | 古事記✅ |
| 史書としての位置 | 成立後あまり広く行われなかった | 国家の正史として見られた | ✅(武田解説) |
| 材料 | 帝紀・旧辞(本辞) | 帝紀と本辞のほか、できるだけ広く材料を集めた | ✅(武田解説) |
| 記述の詳しさ | 時代が下ると簡略(下巻後半は系譜中心) | 時代が下るに従い詳密 | ✅(武田解説) |

- 武田解説は、古事記成立の8年後に日本書紀が成立し、これが正史として見られたことが、古事記が広く行われなかった一因だろうとする。✅

## 神話・内容の相違
| 項目 | 内容 | 確度 |
|---|---|---|
| 出雲神話 | 古事記は出雲神話を重視し、大国主神の物語を詳しく記す。書紀は出雲神話の比重が小さい | ✅(二次資料) |
| 高天原 | 古事記は「高天原」の語を多用する | ✅(二次資料) |
| 異伝の扱い | 書紀は本文に加えて「一書」で異伝を併記する。古事記は一つの筋で通す | 🔶(要確認。一次資料で照合していない) |
| 氏族系譜 | 古事記約201氏、書紀約110氏 | ✅(二次資料) |
| 聖徳太子 | 古事記に聖徳太子の記事なし | ✅(二次資料) |
| 崇峻天皇 | 古事記は崇峻天皇の暗殺を記さない | ✅(二次資料) |
| 欠史八代 | 古事記は系譜中心の記述。皇居・陵墓が葛城・高市地域に集中するとの指摘がある | ✅(二次資料) |
| 歌謡 | 古事記は歌謡を多く載せ、全て一字一音の音仮名。歌曲名を伝えるものが多い | ✅ |

## 同じ説話に別の人物をあてた例
- 武田解説は、同じ説話を日本書紀では別の人物にあてているものがある、とする。✅
- 例: アメノホヒ命は、古事記の伝来ではよく言われないが、その子孫という出雲氏の伝来では忠誠な神とされる。✅(武田解説)

## 比較の注意点
- 記紀の違いは、成立事情(私的な撰録か、国家の編纂か)や、材料とした氏族伝承の違いにも由来する。🔶(一般的理解。一次資料での確認は未了)
- 「古事記は国内向け、日本書紀は対外向け」という説明は、広く流布しているが、学説上の評価は分かれる。🔶(論者・出典は未調査)
