# 用語集

| 用語 | 英語 | 意味 |
|---|---|---|
| 帝紀 | imperial chronicles | 皇統の系譜記録 |
| 旧辞 | old traditions | 古い伝承・説話 |
| 誦習 | memorized recitation | 暗誦して習得すること |
| 変体漢文 | hentai kanbun | 和風化した漢文 |
| 上代特殊仮名遣 | Old Japanese phonetic kana usage | 上代の音節書き分け |
| 記紀 | Ki-Ki | 古事記と日本書紀の併称 |
| 殯 | mogari | 葬る前に遺体を安置する儀礼(神功皇后の項に殯宮が見える) |
| 言向け和す | kotomuke yawasu | 言葉で従わせ平定すること(崇神・景行の条) |
| 御名代 | minashiro | 皇族の名を残すために置いた部(仁徳・允恭などの条) |

## 出典
- 武田祐吉『古事記』角川文庫(1956年〈皇紀2616年・昭和31年〉初版)、[青空文庫「校註 古事記」](https://www.aozora.gr.jp/cards/001518/files/51731_50813.html)の用例による。語義は本文の文脈に基づく簡略な説明で、🔶 辞典での確認が必要。
