# 天地初発と神世七代

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名は武田版の表記を常用漢字化

## 概要
天地の初発に高天原(Takamanohara)に成った神々と、国土が固まる前に成った神々の系列。

## 別天つ神(Kotoamatsukami、五柱)
| 順 | 神名 | 備考 |
|---|---|---|
| 1 | 天之御中主神 | 独神(hitorigami)。身を隠す |
| 2 | 高御産巣日神 | 同上 |
| 3 | 神産巣日神 | 同上 |
| 4 | 宇摩志阿斯訶備比古遅神 | 国が稚く浮脂のようだった時、葦牙のように萌え騰る物から成る |
| 5 | 天之常立神 | 同上 |

## 神世七代(Kamiyonanayo)
| 代 | 神名 |
|---|---|
| 一 | 国之常立神(独神) |
| 二 | 豊雲野神(独神) |
| 三 | 宇比地邇神・妹須比智邇神 |
| 四 | 角杙神・妹活杙神 |
| 五 | 意富斗能地神・妹大斗乃弁神 |
| 六 | 於母陀琉神・妹阿夜訶志古泥神 |
| 七 | 伊耶那岐神・妹伊耶那美神 |

- 独神二柱は各一代、男女一対の十神は二神で一代と数える。✅
- 武田注: 天之御中主は「中心の思想の神格表現」、高御産巣日・神産巣日は「生成の思想の神格表現」。これは武田の解釈である。

## 本文の要点と武田注 ✅
- 本文は「天地の初発の時、高天の原に成りませる神の名は、天の御中主の神。次に高御産巣日の神。次に神産巣日の神。この三柱の神は、みな独神に成りまして、身を隠したまひき」と始まる。
- 武田注(神名の性格):
  - 天之御中主神: 中心・中央の思想の神格表現。空間の表示であるから、活動を伝えない。
  - 高御産巣日神・神産巣日神: 生成の思想の神格表現。事物の存在を「生む」ことで説明する日本神話の原動力。タカミは高大、カムは神秘神聖の意の形容語。この二神の活動は多く伝えられる。
  - 独神(ひとりがみ): 対立でない存在。「身を隠す」は、天地の間に溶け合ったの意。
  - 宇摩志阿斯訶備比古遅神: 葦牙の神格化。神名は男性。「葦牙」は葦の芽で、十分に春になったことを感じている。
  - 天之常立神: 天の確立を意味する神名。
  - 国之常立神・豊雲野神: 武田注は名義不明とし、以下の神名によって土地の成立、動植物の出現、整備等を表現するらしいとする。
  - 阿夜訶志古泥神(妹): 驚きを表現する神名(武田注)。
  - 伊耶那岐神・伊耶那美神: 誘い出す意味の表現(武田注)。
- 注: 神名の語義は武田の説であり、他説がある。名義については神々の個別ページ([goddesses](../../goddesses/README.md)など)も参照。🔶

## 数え方 ✅
- 「上の件、五柱の神は別天つ神」と結ぶ。
- 「国の常立の神より下、伊耶那美の神より前を、并はせて神世七代とまをす」。独神二柱はおのおの一代、双びます十神はおのおの二神を合わせて一代とする。
