# 天地初発と神世七代

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名は武田版の表記を常用漢字化

## 概要
天地の初発に高天原(Takamanohara)に成った神々と、国土が固まる前に成った神々の系列。

## 別天つ神(Kotoamatsukami、五柱)
| 順 | 神名 | 備考 |
|---|---|---|
| 1 | 天之御中主神 | 独神(hitorigami)。身を隠す |
| 2 | 高御産巣日神 | 同上 |
| 3 | 神産巣日神 | 同上 |
| 4 | 宇摩志阿斯訶備比古遅神 | 国が稚く浮脂のようだった時、葦牙のように萌え騰る物から成る |
| 5 | 天之常立神 | 同上 |

## 神世七代(Kamiyonanayo)
| 代 | 神名 |
|---|---|
| 一 | 国之常立神(独神) |
| 二 | 豊雲野神(独神) |
| 三 | 宇比地邇神・妹須比智邇神 |
| 四 | 角杙神・妹活杙神 |
| 五 | 意富斗能地神・妹大斗乃弁神 |
| 六 | 於母陀琉神・妹阿夜訶志古泥神 |
| 七 | 伊耶那岐神・妹伊耶那美神 |

- 独神二柱は各一代、男女一対の十神は二神で一代と数える。✅
- 武田注: 天之御中主は「中心の思想の神格表現」、高御産巣日・神産巣日は「生成の思想の神格表現」。これは武田の解釈である。
