# 海幸山幸と鵜葺草葺不合

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名は武田版の表記を常用漢字化

## 海幸と山幸 ✅
1. 火照命は海佐知毘古として鰭の広物・鰭の狭物を取り、火遠理命は山佐知毘古として毛の麤物・毛の柔物を取る。弟 火遠理が兄と「幸易」(道具の取り替え)を請うて釣針を借りるが、魚に釣針を失う。
2. 火遠理は十拳剣を破って五百鉤・一千鉤を作り償ったが、兄は受け取らず、元の針を返せと責める。海辺で泣き患う火遠理に塩椎神が現れ、事情を問う。✅ 小船で海神の宮へ行く策を教えた点は 🔶(船の名称等は未確認)
3. 海神の宮の井辺の香木に登る火遠理を、海神の女 豊玉毘売の侍女が見つけ、豊玉毘売と婚する。三年住んだ後、火遠理が大きな嘆息をしたため理由を問われ、釣針の件を明かす。
4. 海神は釣針を返し、さらに潮盈つ珠・潮乾る珠を授け、兄を従える方法を教える。兄は次第に貧しくなり荒い心で攻めてきたが、火遠理は珠で兄を溺らせ、救うことを繰り返して悩ませた。✅ 釣針が魚の喉にあった件は 🔶(魚の名は未確認)

## 豊玉毘売の出産 ✅
豊玉毘売命は、天つ神の御子を海原で産むべきでないとして参り出て、海辺の波限に鵜の羽で屋根を葺き、戸の無い八尋殿を作って土で塗り塞ぎ、産む時に入った。✅ 「妾をな見たまひそ」と禁じたが、火遠理が伺い見ると八尋鰐(本文表記)になって匍匐っており、驚き畏れて逃げ退いた。✅
日子穂穂出見命(火遠理)は高千穂の宮に五百八十歳(本文は「五百八拾歳」)在し、陵は高千穂の山の西にある。

## 鵜葺草葺不合命 ✅
天津日高日子波限建鵜葺草葺不合命は、叔母 玉依毘売命に娶い、五瀬命・稲氷命・御毛沼命・若御毛沼命(またの名 豊御毛沼命・神倭伊波礼毘古命)の四柱を生んだ。若御毛沼命が後の神武天皇である。✅(「中つ巻」冒頭の神武天皇に接続)
