# 神生みと黄泉国

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名は武田版の表記を常用漢字化

## 神生み ✅
国を生み終えた後、家屋・海・水・風・木・山・野の神々を生む(大事忍男神、大綿津見神、速秋津日子神・妹速秋津比売神、志那都比古神、久久能智神、大山津見神、鹿屋野比売神ほか)。最後に火之夜芸速男神(別名 火之炫毘古神・火之迦具土神)を生み、美蕃登(みほと)を焼かれて病み臥す。苦しみの中、吐瀉物・屎・尿からも神々が成る(金山毘古神・金山毘売神、波邇夜須毘古神・波邇夜須毘売神、弥都波能売神、和久産巣日神ほか)。

- 武田注: 神々の系列は家屋の成立、水、野焼きと耕作などを語る。🔶 神数の数え方は注に諸説あり、細部は未確認。

## 黄泉国(Yomi no kuni)✅
1. 伊耶那美命は亡くなり、出雲国と伯伎国の境の比婆山に葬られる。伊耶那岐命は十拳剣で迦具土神の頸を斬り、血や身から神々(石析神、建御雷之男神、闇淤加美神ほか、正鹿山津見神以下八山津見神)が成る。
2. 伊耶那岐は黄泉国に追い往き、殿の縢戸から出迎えた伊耶那美に還るよう求める。伊耶那美は「黄泉戸喫(yomotsu-hegui)」をしたと述べ、「我をな視たまひそ」と告げて殿に戻る。
3. 待ちかねた伊耶那岐は櫛の火を灯して覗き、蛆が湧き雷神が成った姿を見て逃げる。
4. 黄泉醜女、八雷神、黄泉軍が追う。黒御鬘→蒲子(山葡萄)、湯津爪櫛→笋(筍)、桃の実を投げて追手を退ける。
5. 最後に伊耶那美自身が追ってきたため、千引の石を黄泉比良坂に引き塞ぎ、石を挟んで離別の言葉を交わす。伊耶那美は「汝の国の人草、一日に千頭絞り殺さむ」、伊耶那岐は「吾は一日に千五百の産屋を立てむ」と応じ、これにより一日に必ず千人が死に、千五百人が生まれる。✅
6. 伊耶那美は黄泉津大神、また道敷大神とも呼ばれる。黄泉比良坂は今の出雲国の伊賦夜坂。✅

## 武田注(要点) ✅
- 迦具土神を斬って成る神: 神話に実在の地名が出る場合は、大抵その神話の伝えられている地方を語る、と武田は述べる(例: 天の香具山、奈良県磯城郡)。
- 泣沢女神: 香具山の麓にあった埴安の池の水神。泣沢の森そのものを神体とする。
- 比婆山: 広島県比婆郡に伝説地がある。
- 十拳剣(十つかみある長い剣)で斬ると、岩石・火力・刀剣の神が成る。武田注によれば、イハサクの神からイハヅツノヲの神までは岩石の神霊、ミカハヤビ・ヒハヤビは火力で、神の系列によって鉄鉱を火力で処理して刀剣を得ることを語る。
- 迦具土神を斬った刀の名は天之尾羽張(別名 伊都之尾羽張): 幅の広い剣の義。水の神と解せられる。別名のイツは威力の意(武田注)。
- 黄泉(よみ): 地下にありとされる空想上の世界。「黄泉」の文字は漢文から来る。
- 殿の縢戸: 宮殿の閉してある戸。殿の騰戸とする伝えもある。
- 黄泉戸喫(よもつへぐい): 黄泉の国の火で作った食物を食ったので黄泉の人となった。同一の火による団結の思想である。
- 湯津爪櫛: 髪を左右に分けて耳の辺で輪にし、それにさす神聖な櫛。櫛は竹で作り、魔よけとして女がさす。
- 「宇士多加礼許呂呂岐弖」の「蛆たかれころろきて」: 蛆がわいてゴロゴロ鳴って、の意。「トロロギテ」とする伝えは誤りとする。
- 黄泉醜女: 黄泉の国の見にくい化け物の女。
- 蒲子(えびかづら): 山葡萄。笋は筍。黒御鬘は植物を輪にして魔よけとして髪の上にのせるもの。
- 黄泉比良坂: 黄泉の国の入口にある坂。黄泉の国に向かって下る。墳墓の構造から来ている。出雲国の伊賦夜坂は島根県八束郡。
- 「現しき青人草」: 現実にある人間。
- 「事戸を度す」: 日本書紀には「絶妻の誓」とある。言葉で戸を立てる、別れの言葉を言う、の意。
- 道敷大神(伊耶那美命の別称): 道路を追いかける神、の注がある。
- 神の数: 武田注に数え方の説明があるが、本リポジトリでは細部を確認していない。🔶
