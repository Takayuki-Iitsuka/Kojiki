# 誓約と天岩戸

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名は武田版の表記を常用漢字化

## 誓約(ukei)✅
1. 須佐之男が天に上ろうとすると山川が動揺し国土が震えた。驚いた天照は、国を奪いに来たと考え、髪を解いてみずらに纏き、八尺の勾玉の五百津の御統珠を巻き、背に千入の靫、腕に稜威の高鞆を付けて武装して迎えた。
2. 須佐之男は邪心なしと述べ、誓約で証明することとなる。互いの持ち物(物実)から子を成す。
3. 先に成った三柱の女子(多紀理毘売命〈奥津宮〉・市寸島比売命〈中津宮〉・田寸津比売命〈辺津宮〉)は須佐之男の物実から成ったので須佐之男の子。宗像の君らが斎く三前の大神。
4. 後に成った五柱の男子は天照の物実から成ったので天照の子。その中に天菩比命(の子 建比良鳥命は出雲国造らの祖)と天津日子根命(国造・直・連らの祖)がいる。
- 五柱の名は、正勝吾勝勝速日天忍穂耳命、天菩比命、天津日子根命、活津日子根命、熊野久須毘命。✅

## 須佐之男の乱行と天岩戸 ✅
1. 須佐之男は「我が心清明し故に我が生める子手弱女を得つ」と勝ちを主張し、天照の営田の畔を離ち、溝を埋め、大嘗を聞こし召す殿に屎を撒いた。天照は咎めず言い直した。
2. 忌服屋で神御衣を織らせている時に、須佐之男は屋根に穴を開け、斑馬を逆剥ぎにして投げ入れた。衣織女は驚いて梭で陰上を衝いて死んだ。
3. 天照は畏れて天石屋戸を開いてこもり、高天原も葦原中国も闇となり、万の妖が起こった。
4. 八百万神は議り、鏡や玉などを用意して儀礼を行う。天宇受売命の舞で八百万の神が笑った。
5. 不思議に思って戸を細く開いた天照に、天児屋命・布刀玉命が鏡を差し出す。覗いた天照を手力男神が引き出し、布刀玉命が尻久米縄を引き渡して「ここより内にな還り入りたまひそ」と請うた。世界は再び明るくなった。
6. 八百万神は議り、須佐之男に千座の置戸を負わせ、鬚と手足の爪を切って祓わせ、神逐いに逐った。✅

## 武田注(要点) ✅
### 誓約
- 須佐之男の昇天: 暴風の襲来する有様で、歴史的には出雲族の襲来を語る(武田注)。
- 天照の武装: 男装される。「八尺の勾玉の五百津の御統の珠」は大きな曲玉を多く緒に貫いたもので、曲玉は玉の威力の発動の思想を表示する。靫は千本の矢を入れて背負う武具。稜威の高鞆は威勢のよい音のする鞆で、トモは皮で球形に作り、左の手にはめて弓を引いた時にそれに当たって音が立つようにする武具。「稜威の雄叫び」は威勢のよい叫び。
- 誓約(うけひ): 神に誓って神意を伺う儀式。種々の方法があり夢が多く使われる。ここは生まれた子の男女の別によって神意を伺う。
- 天安河: 高天原にありとする川。滋賀県の野洲川だともいう。明日香川の古名か。
- 「ぬなとももゆらに」: 玉の音もさやかに。天真名井は神聖な水の井。
- 剣を打ち折り、水に濯いで噛み砕き吹き棄てる所作は、身を清めるために行う。剣を振って水を清め、その水を口に含んで吐く霧の中に神霊が出現するとする。
- 宗像三女神は福岡県の宗像神社の神。奥津宮は福岡県の海上、日本海の沖の島にあり、中津宮は大島にある。
- 後に成った五柱の男子: 正勝吾勝勝速日天忍穂耳命は皇室の御祖先と伝える。天菩比命は出雲氏等の祖先。天津日子根命は主として近畿地方に居住した諸氏の祖先。各種の系統の祖先がこの行事によって出現したとするのは、民族が同一祖から出たとする思想である。熊野久須毘命は出雲国の熊野神社の神。
- 「我が心清明ければ、我が生める子手弱女を得つ」: 日本書紀では反対に、男子が生まれたら須佐之男が潔白とする。武田は、オシホミミ命の出現によって勝ったとするのが原形だろうとする。

### 天岩戸
- 須佐之男の乱行は、田の畦を破り溝を埋め、御食事をなさる宮殿に不浄の物をまき散らす、すべて暴風の災害である。
- 忌服屋: 清浄な機織り場。梭は機を織る時に横糸を巻いて縦糸の中をくぐらせる道具。
- 天石屋戸: 「イハ」は堅固である意を表すためにつけていう。墳墓の入口の石の戸とする説もある。
- 「常夜往く」: 永久の夜が続く。
- 思金神: 思慮智恵の神格化。常世の長鳴鳥は鶏。常世は恒久の世界の義で、空想上の世界から転じて海外をいう。
- 占い: 香具山の鹿の肩の骨をそっくり抜き、天の波波迦(樹名、カバノキ)で焼いて占い、祭の実行方法を定める。
- 真賢木(まさかき): 香具山の繁った木を根と共に掘る。マサカキは繁った常緑木で、今いうツバキ科のサカキに限らない。神聖な清浄な木を引く意味で、山から採ってくる。
- サカキに玉と鏡と麻・楮をつけるのは、神霊を招く意の行事で、他の例では剣をもつける。シラニギテはコウゾ、アヲニギテはアサ。
- 天宇受売: ヒカゲカズラを手次にかけ、マサキノカズラをカヅラにして、小竹の葉を手に持ち、中のうつろの箱のようなものを伏せて踏み鳴らす、神がかりのための用意。
- 尻久米縄: シメ縄。出入禁止の意の表示。
- 千座の置戸: 罪を犯した者に多くの物を出させること。
- 手力男神: 力の神格化。
