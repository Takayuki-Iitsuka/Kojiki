# 崩年干支の西暦候補

> 確度: 干支の算術は ✅(スクリプトで検算。西暦4年を甲子とする)。どの年に比定するかは学説に依存するため、採用はしていない。  |  最終更新: 2026-11-03

古事記は一部の天皇に崩年干支(崩御の年を干支で示したもの)を記す。干支は60年周期なので、西暦には複数の候補が生じる。本ページは候補を列挙するだけで、比定は行わない。比定は学説(例: 日本書紀の紀年との照合、金石文との対応)ごとに異なり、一次資料のみでは確定できない。

年の表記規約(皇紀・和暦)に合わせるには、比定の採用が前提になる。方針が決まるまで、他ページでは干支を本文のまま記している。

## 参考(🔶 既存知識。要出典確認)
- 継体〜推古の六代(継体・安閑・敏達・用明・崇峻・推古)は、6世紀〜7世紀前半の候補(527, 535, 584, 587, 592, 628)を採る説が一般的とされる。
- それ以前の天皇は、どの周期を採るかで説が分かれる。
