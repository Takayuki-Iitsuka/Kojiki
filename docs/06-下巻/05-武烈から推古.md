# 下巻: 武烈〜推古

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

下巻の後半は系譜と宮名・年数・崩年干支が中心で、物語は乏しい。

| 代 | 天皇 | 宮 | 在位・享年・崩年 | 備考 |
|---|---|---|---|---|
| 25 | 小長谷若雀命(武烈) | 長谷の列木宮 | 在位8年 | 太子なし。御子代を定める。 |
| 26 | 袁本杼命(継体) | 伊波礼の玉穂宮 | 御年43歳、丁未年4月9日崩 | 品太王(応神)の五世の孫。三尾君の祖 若比売を娶る。御陵は三島の藍の陵。 |
| 27 | 広国押建金日王(安閑) | 勾の金箸宮 | 乙卯年3月13日崩 | 御子なし。御陵は河内の古市の高屋村。 |
| 28 | 建小広国押楯命(宣化) | 檜垌の廬入野宮 | — | |
| 29 | 天国押波流岐広庭天皇(欽明) | 師木島の大宮 | — | |
| 30 | 沼名倉太玉敷命(敏達) | 他田宮 | 在位14年、甲辰年4月6日崩 | 御陵は川内の科長。 |
| 31 | 橘豊日命(用明) | 池辺宮 | 在位3年、丁未年4月15日崩 | 御陵は石寸の池の上、のち科長の中の陵に移す。 |
| 32 | 長谷部若雀天皇(崇峻) | 倉椅の柴垣宮 | 在位4年、壬子年11月13日崩 | 崩年干支のみ記す。 |
| 33 | 豊御食炊屋比売命(推古) | 小治田宮 | 在位37年、戊子年3月15日癸丑の日崩 | 巻末の天皇。 |

- 代数は現行の皇統譜による。古事記本文に代数の記載はない。🔶
- 宣化・欽明の崩年干支は本文の該当箇所で未確認。享年は安閑〜推古のいずれも本文にない(確認できた範囲)。
- 崇峻の死因(暗殺)は本文に記されない(崩年干支のみ)。✅ → [08-記紀比較](../08-記紀比較.md)
- 聖徳太子: 用明天皇の項に、庶妹 間人穴太部王との間の御子として「上の宮の厩戸の豊聡耳命」が載る。✅ 事績の記述はない。
