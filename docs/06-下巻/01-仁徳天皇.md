# 下巻: 仁徳天皇

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

- 大雀命。難波の高津宮に坐す。大后は葛城の曾都毘古の女 石之日売命。✅
- **聖の御世**: 高山に登り「国中に烟たたず、国みな貧し」と見て、「今より三年に至るまで悉に人民の課役を除せ」と命じ、大殿が破れて雨漏りしても修理しなかった。✅ 茨田堤・茨田屯倉、丸邇池・依網池、難波堀江などの土木も記される。✅
- **吉備の黒日売**: 大后石之日売の嫉妬を恐れて黒日売が帰国。天皇は恋い、淡道島を見るとして吉備へ行幸した。✅
- **皇后石之日売**: 大后が豊楽のため御綱柏を採りに木国へ行く間に、天皇が八田若郎女を召した。大后は山代から筒木の韓人 奴理能美の家に入った。天皇は舎人の鳥山を遣わし、口子臣の仲介を受けたが、大后は応じず。「志都歌の歌い返し」の歌群。✅
- **八田若郎女**: 天皇が八田若郎女に恋して贈る歌。✅
- **速総別王と女鳥王**: 天皇が弟の速総別王を媒として女鳥王を乞うと、女鳥王は速総別に嫁した。天皇は怒り軍を興し、両人は逃れて宇陀の蘇邇で殺された。将軍 山部大楯連が女鳥王の玉釧を奪った件が続く。✅
- **雁の卵**: 日女島で雁が卵を産んだ件で、建内宿禰が歌で答える。✅
- **枯野という船**: 兎寸河の西の高樹を切って作った船の説話。✅
- 御年83歳、丁卯年8月15日崩。御陵は毛受の耳原。✅
