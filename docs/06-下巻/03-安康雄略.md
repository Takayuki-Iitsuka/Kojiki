# 下巻: 安康・雄略

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03  |  神名・人名は武田版の表記を常用漢字化。干支は本文のまま(西暦換算は未実施)

## 安康天皇 ✅
- 穴穂御子。石上の穴穂宮。
- **目弱王の変**: 大日下王を讒言に基づき殺して妻を奪った。のち神牀で昼寝した天皇を、后の連れ子 目弱王が刺殺した。大長谷王(後の雄略)は兄たちを殺し、都夫良意美の家を囲む。都夫良意美は矢が尽きて自害する。
- **市辺押歯王**: 淡海の佐々紀山君の韓袋の誘いで狩に出て、大長谷王に射殺される。その子 意祁王・袁祁王は逃げ去る。

## 雄略天皇 ✅
- 大長谷若建命。長谷の朝倉宮。大日下王の妹 若日下部王を娶る。
- **若日下部王**: 日下の直越の道を河内に出る話など。
- **引田部赤猪子**: 美和河のほとりで衣を洗う童女に会い、嫁がせると約して忘れた。老いた赤猪子が来て、袖を涙で濡らして歌い、天皇は物を賜って返す。「志都歌」の四歌。
- **吉野の宮**: 童女を召す話と阿岐豆野の御猟(虻が天皇の腕を咋った話。続きの詳細は 🔶)。
- **葛城山**: 大きな猪、百官の衣の話。🔶 一言主神の登場は本文に見える語(語の出現のみ確認、内容は未精読)。
- **春日の袁杼比売と三重の采女**: 百枝槻の下の豊楽で伊勢の三重の采女が罪を犯すが、歌を献って赦される。「天語歌」。
- 御年124歳、己巳年8月9日崩。御陵は河内の多治比の高鸇(外字のため省略)。
