## 神名の照合結果(追記)
- 神々280柱の見出しの表記を、武田版校註の本文と機械的に突き合わせた。表記のゆれ(異体字・仮名・之/の等)を正規化すると、本文に見つからないのは固有名を持たない神(走水の渡の神ほか)と、表記差のある約14柱のみ。後者は各ページに「武田版校註の表記」を追記した。
- [ ] 表記差のある神の同定(見出しの神名と武田版の神名が同一神か)を、他の校訂本で確認する
- 神々ページの「親・配偶神・御子神」欄の神名も、武田版校註の本文と突き合わせた。校註の本文に見つからない神名は15ページに限られ、いずれも異体字・別名表記(例: 天之菩卑能命=天菩比命)か、『出雲国風土記』など他書の記述(例: 佐太大神、支佐加比売命)の引用だった。系譜の食い違いは検出されなかった(神名の存在確認のみで、親子・配偶の関係そのものの照合は未了)。
- [ ] 親子・配偶の関係(誰が誰を娶って誰を生んだか)の照合は、校註の系譜部分を読んで行う
- 親子・配偶関係の自動照合(同一文での共起判定)は、神名の表記差と、「次に…」で続く長い系譜文のため誤検出が多く、判定に使えなかった(検査107組のうち69組が「共起せず」だが、須勢理毘売と大国主神のような明白な関係も含まれる)。手作業の抜き取り確認(大年神の系譜: 大宜都比売神=羽山戸神の妻、天知迦流美豆比売=大年神の妻)は本文と一致した。
