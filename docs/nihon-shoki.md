# 日本書紀（にほんしょき）

> 記述方針: 年は「西暦（皇紀○年、和暦）」で表記する（皇紀＝西暦＋660）。

## 2. 成立の経緯

1. **天武天皇10年（681年〈皇紀1341年〉）3月**: 天武天皇が川嶋皇子・忍壁皇子ら十二人に「帝紀及び上古の諸事」の記定を命じた（『日本書紀』天武紀十年三月条）。これが編纂事業の起点とされる。
2. **持統朝〜文武朝**: 事業は継続し、律令制の整備（大宝律令 701年〈皇紀1361年、大宝元年〉）と並行して進んだと考えられる。
3. **720年（皇紀1380年、養老4年）**: 舎人親王らが奏上して完成。

### 2.1 素材（原史料）

- 『帝紀』『旧辞』（古事記序文にも見える、朝廷に伝わった系譜・説話）
- 諸氏族の「墓記」、寺院の縁起、個人の手記（『伊吉博徳書』『難波吉士男人書』など）
- 朝鮮半島系史料: 『百済記』『百済新撰』『百済本記』（いわゆる百済三書）
- 中国史書の引用: 『魏志』（倭人伝）、『晋起居注』など。神功皇后紀で卑弥呼・台与に関わる記事を引き、神功皇后に擬している
- 文飾の典拠: 『淮南子』『芸文類聚』『文選』などの漢籍（例: 神武紀の「八紘（はっこう）を掩（おほ）ひて宇（いへ）と為（せ）む」は『淮南子』系の語句とされる）

## 4. 文体と述作の分担（森博達説）

森博達は、巻ごとの用字・語法（音仮名の用い方、漢文の誤用＝倭習〈わしゅう〉の有無）を分析し、次のように分けた。

| 区分 | 巻 | 特徴 | 想定される述作者 |
|---|---|---|---|
| α群 | 14〜21、24〜27 | 正格漢文。歌謡の音仮名が中国中古音に忠実 | 渡来唐人。具体名は続守言〈しょくしゅげん〉・薩弘恪〈さつこうかく〉とされる［人名は今回未確認］ |
| β群 | 1〜13、22・23、28・29 | 倭習が多く、和化した用法が目立つ | 日本人官僚。山田史御方〈やまだのふひとみかた〉らとされる［人名は今回未確認］ |
| 巻30 | 持統紀 | α群・β群のどちらにも分類しない（森説。確認済） | 不明 |

これは有力な学説であって通説として確定したものではなく、反論もある。

## 5. 特色

1. **対外意識**: 中国王朝・朝鮮諸国との関係を意識した、漢文による正史である（国内向けか対外向けかは論争がある）。
2. **紀年の整備**: 干支（えと）による年次表記を採り、大化（645年〈皇紀1305年〉）以降は年号を併記する。
3. **異伝の併記**: 一書によって複数の伝承を並べ、編者が一つに統合しなかった。
4. **神武即位年**: 辛酉（かのととり）年の正月朔日、紀元前660年（皇紀元年）とする。これは讖緯説（しんいせつ）の辛酉革命説に基づく後世の設定と考えられている（那珂通世〈なかみちよ〉の説。1897年〈皇紀2557年、明治30年〉ごろ。［要確認］）。
5. **歴史事実との関係**: 古い時代ほど紀年が長く引き延ばされており（いわゆる二倍年暦説・紀年延長）、五世紀以前の年代は他史料との照合が必要である。

### 5.1 例: 仏教公伝

- 『日本書紀』: 欽明天皇13年（552年〈皇紀1212年〉）10月、百済聖明王が仏像・経論を献上
- 『上宮聖徳法王帝説』『元興寺縁起』: 戊午年（538年〈皇紀1198年、宣化天皇3年〉）

書紀の年代は、末法思想との関連で作為されたとする見方がある（［要確認］）。

## 6. 古事記との比較

| 観点 | 古事記 | 日本書紀 |
|---|---|---|
| 成立 | 712年（皇紀1372年、和銅5年） | 720年（皇紀1380年、養老4年） |
| 構成 | 3巻（上・中・下） | 30巻＋系図1巻 |
| 撰者 | 太安万侶（おおのやすまろ）。稗田阿礼（ひえだのあれ）が誦習 | 舎人親王ら（官撰の編纂集団） |
| 文体 | 変体漢文（和化漢文）。音訓交用で、訓による日本語表記を重視 | 正格漢文（ただし巻により倭習あり） |
| 形式 | 物語的。歌謡・説話が豊富 | 編年体。年月日を明記 |
| 範囲 | 天地開闢〜推古天皇（628年〈皇紀1288年〉没） | 神代〜持統天皇（697年〈皇紀1357年〉） |
| 異伝 | 原則として一つの筋を採用 | 「一書」で多数の異伝を併記 |
| 年次 | 年号・紀年なし（崩年干支のみ） | 干支・年号あり |
| 神話の重点 | 出雲神話（大国主）が大きな比重 | 出雲系の記事は簡略。高天原系・皇統重視 |
| 初発の神 | 天之御中主神（あめのみなかぬしのかみ） | 本文は国常立尊（くにのとこたちのみこと） |
| 太陽神 | 天照大御神 | 天照大神（本文）。別名に大日孁貴〈おおひるめのむち〉 |
| 国際関係 | 記述は少ない | 中国・朝鮮諸国との外交記事が多い |
| 位置づけ | 『続日本紀』など正史の系列には入らない | 六国史の第一。以後『続日本紀』へ連なる |
| 受容 | 近世に本居宣長『古事記伝』（1798年完成〈皇紀2458年、寛政10年〉）で再評価 | 古代から公的に尊重され、平安期に講書（日本紀講）が行われた |

### 6.1 神話の異同の例

- **国生み**: 記は伊邪那岐命・伊邪那美命が淡道之穂之狭別島（淡路島）から産む。紀の本文では大日本豊秋津洲（本州）を中心とする順で、一書により多数の異伝がある（細部は要確認）。
- **黄泉国**: 記に詳細な黄泉国訪問譚がある。紀では一書に収められ、簡略。
- **天孫降臨**: 記は天照大御神・高木神（高御産巣日神）の命による。紀の本文は高皇産霊尊（たかみむすひのみこと）が主導し、真床追衾（まどこおうふすま）に包まれた皇孫が降る。
- **出雲の国譲り**: 記は建御雷神・建御名方神の力競べなど物語が豊か。紀は簡素で、経津主神・武甕槌神が出雲に降る形で語る。

### 6.2 両書の関係をめぐる論点

- 『古事記』は『日本書紀』の編纂過程で作られた草稿的な性格を持つのか、別の目的で作られた独立の書か。
- 『古事記』偽書説（序文後世偽作説）があるが、通説は成立を認める。
- 「記紀」と一括りにされることが多いが、成立目的・読者・文体が異なり、両者の差を分析することで編纂意図を探る研究方法が主流になっている。

## 7. 受容史

- **平安時代**: 宮中で「日本紀講（にほんぎこう）」と称する書紀の講書が行われた。『釈日本紀』開題が引く康保2年（965年〈皇紀1625年〉）の外記勘申によれば、次のとおり（国史大辞典の記述による）。
  - 養老5年（721年〈皇紀1381年〉）: 書紀披露のための講読とみられる
  - 弘仁3〜4年（812〜813年〈皇紀1472〜1473年〉）
  - 承和10〜11年（843〜844年〈皇紀1503〜1504年〉）
  - 元慶2〜5年（878〜881年〈皇紀1538〜1541年〉）
  - 延喜4〜6年（904〜906年〈皇紀1564〜1566年〉）
  - 承平6年〜天慶6年（936〜943年〈皇紀1596〜1603年〉）
  - 康保は講筵の年ではなく勘申の年。旧稿の「康保の六度」は誤りで、訂正した。
  - 講義録に「日本書紀私記」がある。
- **鎌倉時代**: 卜部兼方（うらべかねかた）『釈日本紀』（鎌倉時代末期、13世紀末ごろ）。
- **室町時代**: 一条兼良『日本書紀纂疏（さんそ）』、吉田兼倶（かねとも）が神道説を付した神代巻の講釈。
- **江戸時代**: 後陽成天皇の勅により、慶長4年（1599年〈皇紀2259年〉）に清原国賢が神代巻上下を古活字版で刊行（慶長勅版。京都大学附属図書館・国立国会図書館の書誌で確認）。全30巻の古活字版は慶長15年（1610年〈皇紀2270年〉）、訓点付き整版は寛文9年（1669年〈皇紀2329年〉）。以後、国学者による研究が進む。
- **近現代**: 津田左右吉（つだそうきち）による文献批判（1910年代〈皇紀2570年代、大正〉）。戦後は考古学・金石文との照合が進む。
