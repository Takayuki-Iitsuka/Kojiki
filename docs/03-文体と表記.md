# 文体と表記

> 確度: ✅(序・武田解説で確認、他は二次資料)  |  最終更新: 2026-11-03

## 全体像
- 本文は変体漢文(hentai kanbun、和風漢文)を基本とする。✅
- 神名・古語・歌謡は、漢字を音だけで使う**音仮名**(phonetic kana)で一字一音に表記する。✅
- 序文は整った漢文で書かれ、本文とは文体が異なる。武田解説は、安万侶が漢文に十分な素養をもちながら、本文では漢文のみを採らず、国語の原形を保存しようと努めた点を功績とする。✅

## 序文が述べる表記方針 ✅
- 上古は言と意がともに朴で、漢字で文章を書くのが難しい。訓だけで書くと詞が心に及ばず、音だけで連ねると事の趣が長くなる。
- そこで、一句の中に音と訓を交えて用い、あるいは一事の内を全く訓で記した。
- 辞理の見えにくい所は注で明らかにし、意況の解りやすい所は注さない。
- 姓の「日下」を「玖沙訶」、名の「帯」の字を「多羅斯」と読む類は、本に従い改めない。
- → 詳細は [01-成立と序文](01-成立と序文.md)

## 三つの表記方法(武田解説の整理) ✅
| 方法 | 内容 |
|---|---|
| 漢文ふうの表記 | 漢文の語序・助字で書く |
| 国語の語序による表記 | 国語の語序に従い、補助詞を音韻で表示する |
| 音韻表記 | 歌謡は全て字音による音韻表記。国語の原形を尊重するため |

- 武田解説は、これらの方法を併用し、常に注を加えて読み方や意義を説明しているとする。✅
- 武田解説は、冒頭の一節を原文で引き、「天地初発之時」の訓みが、アメツチノハジメノトキ、アメツチノハジメテオコリシトキなど複数考えられ、「隠身也」の訓みも「ミミヲカクシタマヒキ」と「カクリミニマシキ」とで対立すると述べる。✅
- 「久羅下那州多陀用弊流」のように音韻表記がなされた部分は「クラゲナスタダヨヘル」と読める一方、他の部分は容易に国語に還せない、とする。✅

## 注と声点
- 本文中に割注(小字の注)があり、訓や音の別を示す。例:「訓高下天云阿麻」(高天の「天」を「アマ」と訓む)、「此神名以音」(この神名は音で読む)。✅(武田解説に引く原文冒頭)
- 一部の神名の傍らに「上」「去」の声点(漢語の四声に由来)が付く。🔶(二次資料の記述。詳細未確認)

## 上代特殊仮名遣
- 歌謡の一字一音表記は、上代特殊仮名遣(Old Japanese phonetic kana usage。上代語で、のちに区別を失う音節を書き分ける仮名遣)の研究の基礎資料である。✅(二次資料)
- 古事記の「モ」の書き分けが、『日本書紀』『万葉集』より古い状態を示すかどうかは、成立時期をめぐる議論と関わる。→ [10-論争点](10-論争点.md) 🔶
