# 概要

> 確度: ✅(二次資料のみ)  |  最終更新: 2026-11-03

『古事記』(Kojiki)は、天地初発から推古天皇の代までを記す、現存最古の歴史書とされる書。序文の日付は和銅5年(712年・皇紀1372年)正月28日。太安万侶が元明天皇に献上したとされる。

## 構成
| 巻 | 範囲 |
|---|---|
| 上巻 | 神代(天地初発〜天孫の系譜) |
| 中巻 | 神武天皇〜応神天皇(神武東征、倭建命、神功皇后ほか) |
| 下巻 | 仁徳天皇〜推古天皇(後半は系譜中心) |
