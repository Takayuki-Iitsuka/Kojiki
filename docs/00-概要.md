# 概要

> 確度: ✅(武田祐吉校註・解説〈青空文庫〉および二次資料で確認。項目ごとに記す)  |  最終更新: 2026-11-03

『古事記』(Kojiki)は、天地初発(てんちはじめ)から推古天皇の代までを記す、現存最古の歴史書とされる書。序文の日付は和銅5年(712年・皇紀1372年)正月28日。太安万侶(おおのやすまろ)が元明天皇に献上したとされる。✅

## 構成
| 巻 | 範囲 | 性格 |
|---|---|---|
| 上巻 | 神代(天地初発〜鵜葺草葺不合命まで) | 神話。解説は「本辞」を材料とし、もと別々の神話を後に継ぎ合わせたものと考える✅ |
| 中巻 | 神武天皇〜応神天皇(神武東征、倭建命、神功皇后ほか) | 帝紀の記事を骨子に本辞を配合✅ |
| 下巻 | 仁徳天皇〜推古天皇(後半は系譜中心) | 同上✅ |

- 中巻・下巻で扱う天皇は、あわせて33代。✅(武田解説)
- 解説によれば、記事が長大複雑で本辞の材料を含むのは、神武・崇神・垂仁・景行・仲哀・応神・仁徳・履中・允恭・安康・雄略・清寧・顕宗の13代。他の20代は主に帝紀によるとみられ、記事が簡単である。✅(武田解説の見解)
- 範囲の細目は [04-上巻](04-上巻/README.md)・[05-中巻](05-中巻.md)・[06-下巻](06-下巻.md)、天皇ごとの情報は [15-歴代天皇一覧](15-歴代天皇一覧.md) を参照。

## 資料としての性格(武田解説による) ✅
- 材料は諸家に伝わっていた**帝紀**(天皇の系譜・事績の記録)と**本辞**(旧辞。神話・伝説・物語)。
- 帝紀は、御名・皇居・治天下・后妃・皇子皇女・崩御・御寿・山陵を、即位の順に配列した事務的な性格をもつ。本辞は説話の形式をもち、信仰・政治・文学・芸能にわたる。
- 帝紀の部分は、古い部分や細部を除けば大体において事実を伝えたものと見られるが、本辞の部分は説話で浮動性が多く、各時代への結びつきはそのままには受け入れがたい、とする。
- 古事記は「時代順に叙述された大きな物語」であると同時に、「時代というつなぎで配列された小説話の集録」とも見られる。
- 以上は武田祐吉(1956年・皇紀2616年刊の角川文庫)の見解であり、後の研究で修正された点がある。🔶(最新の学説は未調査)
