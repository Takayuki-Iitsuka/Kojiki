# 年表

> 確度: 項目ごとに記す(✅ = 一次資料または武田解説で確認、✅二 = 二次資料のみ、🔶 = 未確認)  |  最終更新: 2026-11-03

年は「西暦(皇紀・和暦)」で示す。皇紀 = 西暦 + 660。

## 成立前後
| 西暦(皇紀・和暦) | 事項 | 確度 |
|---|---|---|
| 672〜686年(皇紀1332〜1346年) | 天武天皇の在位。帝紀・本辞の撰録を企図し、稗田阿礼に誦習させる | ✅(解説) |
| 620年(皇紀1280年・推古28年) | 聖徳太子らが天皇記などを撰録(武田解説が帝紀系の書とみる) | ✅(解説) |
| 711年(皇紀1371年・和銅4年)9月18日 | 元明天皇、太安万侶に撰録を命じる | ✅(序) |
| 712年(皇紀1372年・和銅5年)正月28日 | 古事記献上 | ✅(序) |
| 720年(皇紀1380年・養老4年) | 日本書紀成立 | 🔶 |
| 723年(皇紀1383年・養老7年) | 太安万侶没(武田の脚注による) | ✅(校註) |
