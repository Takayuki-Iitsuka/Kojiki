# 大国主神

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 別名: 大穴牟遅神(初名)、八千矛神、宇都志国玉神。[→大国主](../04-上巻/08-大国主.md)
- 兄弟の八十神に迫害されて殺され、蘇生し、根之堅州国で須世理毘売を得る。
- 少名毘古那神とともに国を作り、御諸山の神を祭る。
- 子に事代主神、建御名方神。国譲りで国を天つ神の御子に献る。[→国譲り](../04-上巻/09-国譲り.md)
