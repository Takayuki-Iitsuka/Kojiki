# 大国主神(おおくにぬしのかみ)

> 確度: ✅(武田祐吉校註で確認。解釈は武田の注による。天詔琴など一部は 🔶)  |  最終更新: 2026-11-03

## 物語の流れ
1. **稲羽の素兎**: 兄弟の八十神が稲羽の八上比売に求婚に行き、大穴牟遅に袋を背負わせて従者とした。八上比売は八十神を退け「大穴牟遅神に嫁はむ」と答えた。✅
2. **迫害と蘇生**: 八十神は伯伎国の手間の山本で、焼いた大石を赤猪と偽って落とし、大穴牟遅を殺した。母が神産巣日神に請い、蚶貝比売と蛤貝比売が蘇生させた。再び大樹に挟まれて殺されるが、母が救い、木国の大屋毘古神の許へ逃がした。✅
3. **根之堅州国**: 須世理毘売と出会って婚し、須佐之男命の試練(蛇・呉公・蜂の室、野焼き)を須世理毘売の助けで切り抜けた。須佐之男の太刀・弓矢・天詔琴を持って逃げた。✅(天詔琴は 🔶 未確認)
4. **八十神を追う**: 須佐之男の言葉に従い八十神を追い払い、国を作り始めた。八上比売は須世理毘売を畏れ、子(木俣神)を木の俣に挟んで帰った。✅
5. **神語**: 八千矛神として高志国の沼河比売に求婚する歌物語(歌謡2〜4)と、須勢理毘売の嫉妬、返歌(歌謡5・6)。「こを神語といふ」と結ばれる。✅ → [16-歌謡一覧](../16-歌謡一覧.md)
6. **国作り**: 少名毘古那神(波の穂から天羅摩船に乗り、鵝の皮を衣とする)と国を作り固める。少名毘古那が常世国に渡った後、「吾独して如何にかよくこの国を得作らむ」と憂えた時、海を光らして依り来る神(御諸山の神)が現れ、倭の青垣の東の山の上に祭るよう告げた。✅
7. **国譲り**: 子の事代主神・建御名方神を通じて、国を天つ神の御子に献る。→ [09-国譲り](../04-上巻/09-国譲り.md)

## 検討点
- 武田解説は、高天原系統と出雲系統の神話が、融合したものと融合しないまま接続したものがあるとする。大国主神の物語は後者を含む。✅
- 出雲大社の創建伝承、出雲国風土記・日本書紀との異同は、本リポジトリでは未調査。🔶
