## 天孫降臨
1. 国が平定されたので、天照大御神と高木神は忍穂耳命に降臨を命じた。忍穂耳命は、降る支度の間に子の邇邇芸命が生まれたと答え、邇邇芸命が降ることになった。✅
2. 天八衢に、上は高天原を、下は葦原中国を光らす神(猿田毘古神)がいた。天宇受売神が問い、身元を確かめた。✅
3. **五伴緒**: 天児屋命(中臣連の祖)、布刀玉命(忌部首の祖)、天宇受売命(猿女君の祖)、伊斯許理度売命(鏡作連の祖)、玉祖命(玉祖連の祖)が随伴した。✅
4. **副えられたもの**: 八尺の勾玉、鏡、草那芸剣、常世思金神、手力男神、天石門別神。✅
5. 天忍日命(大伴連の祖)と天津久米命(久米直の祖)が武装して先導した。✅
6. 邇邇芸命は「此地は韓国に向ひ…朝日の直刺す国、夕日の日照る国なり。かれ此地ぞいと吉き地」と宣り、宮柱太しり、高天原に氷椽高しりて坐した。✅
- 「三種の神器」の語は本文に見えない。鏡・勾玉・草那芸剣の取り扱いは、後世の「神器」観念との関係を含めて別途調査する。🔶

## 木花之佐久夜毘売
- 笠沙の岬で、大山津見神の女 神阿多都比売、またの名 木花之佐久夜毘売に会い、求婚した。姉の石長比売は醜いために返し、佐久夜毘売とのみ一宿婚した。大山津見神は石長比売を返されたことを恥じた。✅
- 一夜で妊んだことを疑われた佐久夜毘売は、戸の無い八尋殿に入り、火を著けて産んだ(火照命・火須勢理命・火遠理命)。✅
