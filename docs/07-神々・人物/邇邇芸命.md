# 邇邇芸命(天津日高日子番能邇邇芸命)

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 天照大御神の子 忍穂耳命の子。五伴緒・三つの宝物を伴って、竺紫の日向の高千穂に天降る。[→天孫降臨](../04-上巻/10-天孫降臨.md)
- 木花之佐久夜毘売を娶り、火照命・火須勢理命・火遠理命が生まれる(火中出産)。[→同](../04-上巻/10-天孫降臨.md)
- 子の火遠理命(日子穂穂出見命)は海幸山幸の物語の主人公。[→海幸山幸](../04-上巻/11-海幸山幸と鵜葺草葺不合.md)
