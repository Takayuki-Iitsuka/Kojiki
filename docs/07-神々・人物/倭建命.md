# 倭建命(小碓命)

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 景行天皇の御子。西征で熊曾建から倭建の名を献られ、出雲建を偽刀で討つ。東征の後、伊服岐山で病を得て能煩野で亡くなり、白鳥となって飛び去る。[→景行天皇と倭建命](../05-中巻/05-景行天皇と倭建命.md)
- 歌謡24(出雲建)、歌謡31(国思歌)ほか。[→歌謡一覧](../16-歌謡一覧.md)
