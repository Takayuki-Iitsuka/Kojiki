# 倭建命(やまとたけるのみこと)

> 確度: ✅(武田祐吉校註で確認)  |  最終更新: 2026-11-03

## 西征
- 兄が朝夕の大御食に出て来ないことを「ねぎ教え覚せ」と命じられた小碓命は、厠に入る兄を捕らえ、手足をひき折り、薦に包んで投げ棄てた。天皇はその荒い性情を恐れ、熊曾建二人の討伐を命じた。✅
- 姨の倭比売命の衣裳を着て童女の姿となり、宴の酣に熊曾建の胸を刺し通した。熊曾建は討たれる際に名を献り、「今よ後、倭建御子と称へまをさむ」と述べた。✅
- 出雲建とは結交して赤檮の偽刀を作り、肥河で共に沐浴した。先に上がって刀を取り替え、「いざ刀合はせむ」と誘い、討ち殺した(歌謡24)。✅

## 東征
- 東方十二道の荒ぶる神・服わぬ人を言向け和すよう命じられる。✅
- 尾張で美夜受比売の家に入り、帰りに婚すると約した。✅
- 走水の海で渡の神が波を立てたため、后(弟橘比売)が身を投じた。御櫛が七日後に海辺に寄り、御陵を作った。✅
- 蝦夷らを言向け、酒折宮で歌を詠んだ。✅
- 尾張に還り、美夜受比売と御合し、草薙剣を置いて伊服岐山の神を取りに出た。✅

## 最期
1. 徒手で取れると言って伊服岐山に登り、白猪に遇った(神の化身)。✅
2. 当芸野で「吾が足得歩まず」と詔り、三重村で「吾が足三重の勾なして、いたく疲れたり」と詔った。✅
3. 能煩野で国思歌「倭は国のまほろば たたなづく青垣 山隠れる倭し美し」(歌謡31)を詠み、病が急になった。✅ → [16-歌謡一覧](../16-歌謡一覧.md)
4. 倭の后や御子たちが下って御陵を作ると、八尋白智鳥となって天翔り、浜に向かって飛び去った。后たちと御子たちは小竹の苅杙に足を切りつつ追った。四つの歌は大御葬に歌われる。✅
