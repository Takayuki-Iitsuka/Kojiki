# 伊耶那美命(いざなみのみこと)

> 確度: ✅(武田祐吉校註で確認した記述。解釈は武田の注による)  |  最終更新: 2026-11-03

## 経歴
1. **国生み**: 淤能碁呂島で天御柱を巡る際、最初に女神から声をかけたため生まれた子は良くなかった(武田注: ヒルのような子)。太卜の占いにより巡り直し、男神から声をかけ直して島々を生んだ。✅ → [02-国生み](../04-上巻/02-国生み.md)
2. **神生み**: 家屋・海・水・風・木・山・野の神々を生む。最後に火之夜芸速男神を生み、美蕃登を焼かれて病み臥した。苦しみの中、吐瀉物・屎・尿からも神々が成る(金山毘古神・金山毘売神、波邇夜須毘古神・波邇夜須毘売神、弥都波能売神、和久産巣日神ほか)。✅
3. **死**: 亡くなり、比婆山に葬られた。✅
4. **黄泉国**: 殿の縢戸から出迎え、「黄泉戸喫」をしたと述べ、「我をな視たまひそ」と告げて殿に戻る。見られた後、黄泉醜女・八雷神・黄泉軍を遣わし、最後は自ら追った。千引の石を挟んで「汝の国の人草、一日に千頭絞り殺さむ」と言った。✅ → [03-神生みと黄泉国](../04-上巻/03-神生みと黄泉国.md)
5. この結果、人は一日に千人死に、千五百人が生まれるとされる。✅
