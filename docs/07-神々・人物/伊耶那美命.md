# 伊耶那美命

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 神世七代の最後の女神。伊耶那岐命の妹。[→天地初発](../04-上巻/01-天地初発と神世七代.md)
- 国生みで、最初に女神から声をかけたため子が良くなかった(ヒルのような子とする武田注)。[→国生み](../04-上巻/02-国生み.md)
- 火之夜芸速男神(火之迦具土神)を生んで病み臥し、亡くなる。比婆山に葬られる。のち黄泉津大神・道敷大神と呼ばれる。[→黄泉国](../04-上巻/03-神生みと黄泉国.md)
