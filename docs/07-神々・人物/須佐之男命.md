## 経歴(時系列)
1. **委任と号泣**: 委任された海原を治めず、八拳須が胸元に至るまで泣きいさちった。青山は枯山のように枯れ、河海は乾き、悪神の声が蠅のように満ち、万の妖が起こった。理由を問われ「妣の国根之堅州国に罷らむと思ふ」と答え、伊耶那岐命に追われる。✅ → [04-禊と三貴子](../04-上巻/04-禊と三貴子.md)
2. **天に上る**: 天照大御神に事情を告げようと天に上る時、山川が動き国土が震えた。✅
3. **誓約**: 邪心がないことを示す誓約で、宗像三女神を得る。「我が心清明ければ我が生める子手弱女を得つ」と勝ちを主張した。✅
4. **乱行と追放**: 営田の畔を離ち、溝を埋め、大嘗の殿に屎を撒き、忌服屋の屋根を穿って逆剥ぎにした馬を投げ入れる。天照は岩戸にこもる。のち、千座の置戸を負わされ、鬚と手足の爪を切って祓われ、神逐いされた。✅ → [05-誓約と天岩戸](../04-上巻/05-誓約と天岩戸.md)
5. **大気都比売**: 食物を乞い、料理を穢いと見て大気都比売神を殺す。その身から蚕・稲・粟・小豆・麦・大豆が生じ、神産巣日御祖命が種とした。✅
6. **八俣大蛇退治**: 出雲の肥河上の鳥髪に降り、足名椎・手名椎・櫛名田比売に会う。櫛名田比売を湯津爪櫛に変えて御髻に挿し、八塩折の酒で酔わせた八俣大蛇を十拳剣で斬る。尾から草薙の剣を得て天照に献上する。✅
7. **須賀の宮**: 須賀の地で「吾此地に来て、我が御心清々し」と言い、宮を作る。最初の歌(歌謡番号1)「や雲立つ 出雲八重垣…」を詠んだ。✅ → [06-八俣大蛇と須佐之男](../04-上巻/06-八俣大蛇と須佐之男.md)
8. **根之堅州国**: 大国主神に試練を与え、後に「大国主神」の名を授ける。✅ → [08-大国主](../04-上巻/08-大国主.md)

## 性格(武田注)
- 暴風の神であり、出雲系の英雄でもある。✅
- 武田解説は、出雲系のスサノヲ命が高天原系の神話に現れる点を、天武天皇による新たな整理の結果とは考えにくく、古い結合によるとみる。✅
