# 建速須佐之男命(須佐之男命)

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 伊耶那岐命の鼻から成った三貴子の一。海原を委ねられたが、泣きわめいて国を治めず、根之堅州国に行きたいと言って追い払われる。[→禊と三貴子](../04-上巻/04-禊と三貴子.md)
- 天照との誓約で三女神を得る。乱行の末、千座の置戸を負わされ、鬚と手足の爪を切って祓われ、神逐いされる。[→誓約と天岩戸](../04-上巻/05-誓約と天岩戸.md)
- 大気都比売神を殺し、穀物の種が生じる。出雲で八俣大蛇を退治し、櫛名田比売を妻とし、須賀に宮を作る。[→八俣大蛇](../04-上巻/06-八俣大蛇と須佐之男.md)
- 根之堅州国で、大国主に試練を与え、「大国主神」の名を授ける。[→大国主](../04-上巻/08-大国主.md)

## 出典
