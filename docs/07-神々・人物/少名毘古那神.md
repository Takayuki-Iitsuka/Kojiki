# 少名毘古那神

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 波の穂から天羅摩船に乗り、鵝の皮を衣服として来た神。大国主と国作りを行う。[→大国主](../04-上巻/08-大国主.md)
- 常世国に渡った後、大国主は「吾独して如何にかよくこの国をえ作らむ」と憂え、御諸山の神が現れた。
