# 伊耶那岐命

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 神世七代の最後の男神。妹は伊耶那美神。[→天地初発](../04-上巻/01-天地初発と神世七代.md)
- 伊耶那美とともに天沼矛で淤能碁呂島を作り、国生み・神生みを行う。[→国生み](../04-上巻/02-国生み.md)
- 黄泉国から逃げ帰り、禊で天照大御神・月読命・建速須佐之男命(三貴子)を得る。[→黄泉国](../04-上巻/03-神生みと黄泉国.md)、[→禊と三貴子](../04-上巻/04-禊と三貴子.md)
- 武田注: イザナギ信仰は淡路方面に広がっていた。真福寺本は「淡海の多賀」とする。
