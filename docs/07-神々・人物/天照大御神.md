# 天照大御神

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 伊耶那岐命の左の御目から成った三貴子の一。高天原を知らすよう委ねられる。[→禊と三貴子](../04-上巻/04-禊と三貴子.md)
- 須佐之男と誓約を行い、天岩戸にこもる。[→誓約と天岩戸](../04-上巻/05-誓約と天岩戸.md)
- 草薙大刀が献上された。[→八俣大蛇](../04-上巻/06-八俣大蛇と須佐之男.md)
- 葦原中国の統治を子の忍穂耳命に委ね、国譲りを経て天孫降臨となる。[→国譲り](../04-上巻/09-国譲り.md)、[→天孫降臨](../04-上巻/10-天孫降臨.md)
- 鏡について「もはら我が御魂として、吾が御前を拝くがごと、斎きまつれ」と言い、鏡は五十鈴宮に祭られる(武田注)。
