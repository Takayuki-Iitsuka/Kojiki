## 出現と委任
- 禊の末、左の御目から天照大御神、右の御目から月読命、鼻から建速須佐之男命が成る。伊耶那岐命は「吾は子を生み生みて、生みの終に、三柱の貴子を得たり」と大いに歓んだ。✅
- 伊耶那岐命は御頸珠の玉の緒をゆらゆらと取りゆらかして天照大御神に与え、「汝が命は高天の原を知らせ」と委任した。✅
- → [04-禊と三貴子](../04-上巻/04-禊と三貴子.md)

## 誓約(うけひ)
- 須佐之男命が天に上る時、山川が動き国土が震えた。天照大御神は「我が国を奪はむ」と考え、髪をみずらに纏き、八尺の勾玉の御統珠を巻き、千入の靫・稜威の高鞆を付けて武装して迎えた。✅
- 誓約で、天照の物実(ものざね)から成った五柱の男子は天照の子、須佐之男の物実から成った三柱の女子(宗像三女神)は須佐之男の子と分けた。✅
- 武田注: 須佐之男の「我が心清明ければ」の言葉につき、日本書紀では逆に男子が生まれたら須佐之男が潔白とする。✅
- → [05-誓約と天岩戸](../04-上巻/05-誓約と天岩戸.md)

## 天岩戸
- 須佐之男の乱行(営田の畔を離ち、溝を埋め、大嘗を聞こし召す殿に屎を撒く等)を、天照は初め咎めずに言い直した。のち、忌服屋の屋根を穿って馬の皮を投げ入れる事件があり、天照は畏れて天石屋戸にこもった。高天原も葦原中国も闇となり、万の妖が起こった。✅
- 八百万の神が議り、天宇受売命が舞い、神々が笑った。「何とかも天宇受売は楽しき」と怪しんで戸を細く開いた天照に、鏡を差し出し、手力男神が引き出した。布刀玉命が尻久米縄を引き渡し、「ここより内にな還り入りたまひそ」と請うた。✅
- 須佐之男は千座の置戸を負わされ、鬚と手足の爪を切って祓われ、神逐いされた。✅

## 草薙の剣
- 須佐之男が八俣大蛇を退治して得た草薙の剣(武田版は草薙大刀)は、天照大御神に献上された。✅ → [06-八俣大蛇と須佐之男](../04-上巻/06-八俣大蛇と須佐之男.md)

## 国譲りから天孫降臨
- 天照大御神は「豊葦原の千秋の長五百秋の水穂国は、我が御子正勝吾勝勝速日天忍穂耳命の知らす国」と委任し、高御産巣日神(高木神)と共に諸神に諮って使者を遣わした。✅ → [09-国譲り](../04-上巻/09-国譲り.md)
- 忍穂耳命は降る支度の間に子の邇邇芸命が生まれたため、邇邇芸命が降ることになった。天照は高木神の命で、八尺の勾玉、鏡、草薙の剣と、思金神・手力男神・天石門別神を副えて邇邇芸命に与えた。✅
- 鏡について天照は、「これの鏡は、もはら我が御魂として、吾が御前を拝くがごと、斎きまつれ」と述べた。✅
- 武田注: 鏡と思金神は五十鈴宮に拝き祭られ、登由宇気神は外つ宮の度相にいます。✅ → [10-天孫降臨](../04-上巻/10-天孫降臨.md)
