# 建御雷神

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 伊都之尾羽張神の子。天鳥船神を副えられ、国譲りの使者として出雲の伊耶佐の小浜に降り、十掬剣を波の穂に逆さに刺し立て、その切先に坐して大国主に問う。[→国譲り](../04-上巻/09-国譲り.md)
- 建御名方神と力比べをし、手を取って追い、科野国の州羽の海まで追い詰めた。
- 迦具土神の血から成った神の一柱としても名が見える。[→黄泉国](../04-上巻/03-神生みと黄泉国.md)(武田注に、国譲りと神武東征の条への言及がある。)
