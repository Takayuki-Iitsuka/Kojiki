# 神功皇后(息長帯日売命)

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 仲哀天皇の太后。神懸かりし、天皇の崩後に大祓を行い、新羅・百済を服属させ、鎮懐石で出産を遅らせる。[→仲哀天皇と神功皇后](../05-中巻/06-仲哀天皇と神功皇后.md)
- 香坂王・忍熊王との戦いに勝ち、気比大神の件、待酒の歌がある。
- 漢風諡号・皇后としての代数扱いは本文にない。🔶
