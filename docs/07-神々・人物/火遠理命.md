# 火遠理命(日子穂穂出見命・山佐知毘古)

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 邇邇芸命と木花之佐久夜毘売の子。兄は火照命(海佐知毘古)。[→海幸山幸](../04-上巻/11-海幸山幸と鵜葺草葺不合.md)
- 兄の釣針を失い、塩椎神の導きで海神の宮に行き、豊玉毘売命と婚した。潮盈つ珠・潮乾る珠で兄を従えた。
- 子は鵜葺草葺不合命(神武天皇の父)。高千穂の宮に五百八拾歳在した。
