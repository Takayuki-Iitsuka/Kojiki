# 櫛名田比売

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 足名椎・手名椎の女。八俣大蛇の生贄となる所を須佐之男に救われ、湯津爪櫛に変えられて御髻に挿された。[→八俣大蛇](../04-上巻/06-八俣大蛇と須佐之男.md)
- 須佐之男との間に八島士奴美神を生んだ。
