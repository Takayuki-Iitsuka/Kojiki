# 猿田毘古神

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 邇邇芸命の天降りの際、天八衢に居て上は高天原を光らし下は葦原中国を光らす神。天宇受売神が問い、先導を務めた。[→天孫降臨](../04-上巻/10-天孫降臨.md)
- 天宇受売命の子孫は猿女君として、その名を負って仕えた。
