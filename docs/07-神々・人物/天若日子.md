# 天若日子

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 天菩比神に続く葦原中国への使者。天つ神から授かった弓矢で任に当たったが、下照比売を娶り八年復奏しなかった。[→国譲り](../04-上巻/09-国譲り.md)
- 問責の使者 鳴女(雉)を射殺し、その矢が返されて自身に当たって死んだ。喪屋の場面では阿遅志貴高日子根神と混同された。
