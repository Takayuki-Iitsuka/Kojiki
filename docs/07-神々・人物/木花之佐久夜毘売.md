# 木花之佐久夜毘売(神阿多都比売)

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 大山津見神の女。笠沙の岬で邇邇芸命と会い、一宿婚した。姉に石長比売があり、醜いために返された。[→天孫降臨](../04-上巻/10-天孫降臨.md)
- 妊んだことを疑われ、戸の無い八尋殿に火を著けて火照命・火須勢理命・火遠理命を産んだ。

## 出典
- 武田祐吉『古事記』角川文庫(1956年〈皇紀2616年・昭和31年〉初版)、[青空文庫「校註 古事記」](https://www.aozora.gr.jp/cards/001518/files/51731_50813.html)。書き下し文。
