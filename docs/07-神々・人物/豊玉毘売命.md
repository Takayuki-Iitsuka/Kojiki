# 豊玉毘売命

> 確度: ✅(武田祐吉校註で確認した記述のみ。本ページは既存の各ページの要約)  |  最終更新: 2026-11-03

- 海神の女。火遠理命が海神の宮の井辺の香木に登った時に会い、婚した。[→海幸山幸](../04-上巻/11-海幸山幸と鵜葺草葺不合.md)
- 妊んで海辺に来て、鵜の羽で屋根を葺く産屋(戸の無い八尋殿)で産む際、「妾をな見たまひそ」と禁じたが、八尋鰐になっていたのを見られた。
